# 🏢 지금 가는 중 (Jigum Ganun Jung)

> **중앙대학교 교내 공간의 실시간 혼잡도를 제보하고 탐색하는 참여형 교내 공간 정보 플랫폼**

본 프로젝트는 학생들이 공강 시간이나 식사 시간에 공부할 곳, 식사할 곳, 쉴 곳을 찾아 교내를 방황하며 겪는 동선과 시간의 낭비를 해결하기 위해 기획된 **실시간 교내 공간 혼잡도 제보 및 추천 서비스**입니다.

---

## 🌟 핵심 가치

### 1. 포인트 보상 기반의 자발적 정보 순환 구조
* 서비스의 실시간 혼잡도 데이터는 학생들의 능동적인 현장 제보를 동력으로 유지됩니다.
* 현장 정보를 제보하여 포인트를 획득하고, 이 포인트로 다른 장소의 혼잡도를 열람(소모)하게 만드는 **"생산과 소모의 토큰 이코노미"**를 구축했습니다.
* 이러한 자발적인 피드백 루프를 통해 관리자의 개입 없이도 교내 실시간 정보가 끊임없이 자발적으로 갱신되고 유지됩니다.

### 2. 지능형 가중 평균 혼잡도 연산 엔진
* 개별 제보자의 주관적 판단에만 의존하지 않고, 장소에 누적된 여러 제보 데이터를 유기적으로 병합하여 신뢰성 높은 단일 혼잡도 수치를 도출합니다.
* **시간 경과에 따른 가중치 감쇠 (Time-Decay)**: 30분 이내의 제보만 유효하게 취급하며, 최근 제보일수록 반영 비율을 높게 설정하고 시간이 흐를수록 선형적으로 감쇠시킵니다.
* **유저 신뢰도 반영 (Reporter Trust Score)**: 제보자의 활동 신용도를 복합적인 가중치 팩터로 연산에 포함시켜, 허위 제보나 일시적인 노이즈 데이터의 영향력을 최소화합니다.

### 3. 공간 목적별 5단계 맞춤형 가이드라인
* 장소의 쓰임새(식사, 공부, 휴식)에 부합하는 사실 묘사 기반(줄서기, 빈자리 유무, 소음 수준 등)의 5단계 설명문을 동적으로 매핑합니다.
* 제보자에게는 선택을 망설이게 하는 심리적 장벽을 제거하고, 열람자에게는 실질적인 현장 이용 가능 가능선을 직관적으로 전달합니다.

## 🛠️ 주요 기능

### 📍 실시간 장소 혼잡도 제보 & GPS 검증
* 현장에 있는 사용자가 GPS 오차 검증 범위 내에 있을 경우 손쉽게 실시간 제보를 등록할 수 있습니다.
* 데이터 공백 장소(최근 30분간 제보 없음)에 첫 제보 시 특별 추가 보상 포인트를 부여하는 차등 기여 시스템을 갖추고 있습니다.

### 🪙 포인트 & 랭킹 선순환 에코 시스템
* 사용자가 공간 혼잡도를 제보하면 포인트를 획득합니다.
* 획득한 포인트는 다른 장소의 잠겨 있는 실시간 혼잡도 게이지를 잠금 해제(5분 열람권 구매)하는 데 활용됩니다.
* 누적 포인트, 제보 횟수, 신뢰도 점수를 종합 산출하는 `랭킹 TOP 10` 리더보드를 제공하여 유저들의 자발적인 참여를 독려합니다.

### 🤖 Gemini AI 챗봇 추천 비서
* Gemini API를 연동하여 교내 공간에 대한 지능형 추천 서비스를 제공합니다.
* 사용자가 "지금 310관에 팀플하기 좋은 조용한 곳 있어?" 혹은 "배고픈데 근처 밥 먹을 만한 한적한 곳 추천해 줘"라고 질문하면, 현재 실시간 가중 평균 혼잡도 데이터와 장소 목적을 분석하여 완벽한 최적의 대안을 제안합니다.

### 📊 실시간 제보 시뮬레이터 (Simulator)
* 테스트 및 시연의 편의성을 위해 가상 시간 배속 엔진 및 제보 시뮬레이터를 갖추고 있습니다.
* 자동으로 랜덤 제보를 발생시키거나 특정 혼잡도(예: 1~2단계 위주 또는 4~5단계 위주)가 가중되어 발생하도록 설정하여 혼잡도 알고리즘과 AI 챗봇 추천 기능의 반응성을 입증할 수 있습니다.

## 📂 프로젝트 폴더 구조

```text
src/
├── components/         # UI 화면 및 공통 위젯 컴포넌트
│   ├── screens/        # DetailScreen(상세), ReportInputScreen(제보 입력), MyInfoScreen(내 정보) 등
│   └── Simulator.tsx   # 실시간 가상 제보 생성 시뮬레이터 대시보드
├── context/            # 전역 상태 관리 Context (UserContext, PlaceContext)
├── data/               # 장소 위치 리스트 메타데이터 및 유저 시드 데이터 (seedStore.json)
├── types/              # TypeScript 인터페이스 선언
└── utils/              # 유틸리티 및 알고리즘 헬퍼 함수
    ├── crowdAnalyzer.ts # 시간 감쇠 가중 평균 계산 및 목적별 5단계 설명문 매핑
    ├── timeSpeed.ts    # 시뮬레이터용 가상 시간 배속 엔진
    └── timeFormatter.ts# 상대 시간(n분 전) 및 타임라인 포맷터
```
